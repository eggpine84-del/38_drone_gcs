# 웹 기술 스택 결정 가이드 (AI 즉시 판정용)

## 1. AI 스택 자동 판정표 (Decision Matrix)

| 프로젝트 조건 / 요구사항 | 추천 스택 | 프론트 / 백엔드 분리 여부 | 핵심 이유 |
|---|---|---|---|
| **[기본] 대시보드 / 사내툴 / 관리자 / 1인 AI 개발** | **FastAPI + jinja2 + HTMX + Tailwind** | 단일 파이썬 스택 (빌드 없음) | npm 지옥 0%, 배포 단순, AI 오류 최저 |
| **B2C 대중 서비스 / 모바일 앱 / 화려한 애니메이션** | **FastAPI + Next.js (React)** | 백엔드 API + 프론트엔드 분리 | shadcn/ui 등 화려한 UI 컴포넌트 생태계 |
| **초당 수만 건 트래픽 / 금융 체결 / 단일 바이너리 배포** | **Go + HTMX (또는 React)** | Go 단일 바이너리 | 극한의 처리 속도, 메모리 10MB 절약 |

---

## 2. 3초 결정 규칙 (Deterministic Rules)

```text
[규칙 1: 백엔드]
IF (금융 체결 OR 초당 1만건 트래픽 OR 단일 바이너리 배포):
    ➔ Backend = Go
ELSE:
    ➔ Backend = Python (FastAPI) [기본값]

[규칙 2: 프론트엔드]
IF (B2C 대중 앱 OR 디자이너 협업 OR 복잡한 캔버스 그래픽):
    ➔ Frontend = Next.js / React (TypeScript)
ELSE:
    ➔ Frontend = HTMX + Tailwind CSS (No-Build, 파이썬 일체형) [기본값]
```

---

## 3. 기본 채택 템플릿: [B안] FastAPI + HTMX
- 특별한 명시적 요구(B2C 모바일, 대용량 트래픽)가 없는 한, **모든 관리자/대시보드 프로젝트는 B안(FastAPI + jinja2 + HTMX + Tailwind)을 기본 표준으로 자동 채택**한다.

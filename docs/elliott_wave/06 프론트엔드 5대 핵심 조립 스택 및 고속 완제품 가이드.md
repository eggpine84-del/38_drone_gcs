# [06 프론트엔드 5대 핵심 조립 스택 및 고속 완제품 가이드]

## 1. 개요 및 목적 (Fast-Track Philosophy)

본 문서는 프론트엔드 개발 시 발생하는 불필요한 밑바닥 코딩 노가다를 제거하고, **외주 개발팀 5명분의 업무량을 1인 체제에서 수 분 만에 조립 완성**하기 위한 5대 표준 치트키 스택을 정의합니다.

모든 신규 기능 및 고도화 작업은 아래 5대 검증된 완제품 스택의 결합으로 진행하여, 결함 0%와 배포 속도 극대화를 달성합니다.

---

## 2. 프론트엔드 5대 고효율 조립 스택 명세

### [스택 1: S-1] 화면 디자인 및 컴포넌트 (Tailwind + shadcn/ui)
- **기존 고통**: 픽셀 1px 오차, 폰트 찌그러짐, 브라우저/iframe 하단 짤림 디버깅 (소요시간 2시간)
- **치트키 적용**: `docs 05` 및 `templates 02`의 A원단(토큰) + B블록(레고 블록) 규격 결합
- **사장님 효과**: "P-2 토스 스타일에 B-3 입력창, B-7 전광판 넣어라" 한마디로 30초 컷

### [스택 2: S-2] 비동기 데이터 통신 및 캐싱 (TanStack Query / SWR)
- **기존 고통**: 로딩 스피너 구현, 서버 에러 분기, 광클(연타) 방지, 새로고침 시 데이터 증발 방지 (코드 수백 줄)
- **치트키 적용**: 단 1줄의 선언형 훅(`useQuery`)으로 자동 처리
- **핵심 기능**:
  1. **Zero-Loading-Jank**: 백그라운드에서 데이터를 몰래 가져와 화면 덜컹거림 없이 즉시 갱신
  2. **Smart-Cache**: 이미 조회한 주식 시세는 0.001초 만에 캐시에서 즉시 노출
  3. **Auto-Retry**: 네트워크 불안정 시 3회 자동 재시도 후 안전한 폴백 제공

### [스택 3: S-3] 인터랙티브 퀀트 차트 (Tremor / Recharts)
- **기존 고통**: SVG 베지어 곡선 좌표 계산, 모바일 종횡비 왜곡, 마우스 호버 좌표 수동 연산 (소요시간 반나절)
- **치트키 적용**: 숫자 배열(`[80000, 100000, 105000]`)만 주입하면 끝나는 완제품 차트 블록
- **핵심 기능**:
  1. 마우스나 손가락을 올리면 해당 파동의 가격과 레이블이 떠오르는 스마트 툴팁 내장
  2. 어떤 모바일 화면 폭에서도 가로 스크롤 없이 부드럽게 줄어드는 완전 반응형 지원

### [스택 4: S-4] 회원가입 및 소셜 로그인 (Clerk / Supabase Auth)
- **기존 고통**: 카카오/구글 개발자센터 세팅, JWT 토큰 발급, DB 비밀번호 해싱, 세션 쿠키 관리 (외주비 300~500만 원)
- **치트키 적용**: 완제품 로그인 모달 컴포넌트 1줄 임베드
- **핵심 기능**:
  1. 카카오톡, 구글, 네이버 1초 원클릭 소셜 로그인 팝업 즉시 제공
  2. 유저 관리 대시보드(누가 가입했는지, 최근 로그인 언제인지) 관리자 페이지 공짜 탑재

### [스택 5: S-5] 사용자 입력 실시간 검증 (Zod)
- **기존 고통**: "숫자만 넣어라", "0보다 커야 한다", "고점이 저점보다 커야 한다" if문 수십 개와 빨간 안내창 수동 코딩
- **치트키 적용**: 검증 규칙 3줄 선언으로 입력 즉시 실시간 피드백
- **핵심 기능**:
  1. 유효하지 않은 값 입력 시 실시간 붉은색 테두리 및 정확한 한글 안내 자동 출력
  2. 잘못된 데이터가 백엔드로 전송되는 것을 클라이언트에서 100% 원천 차단(T1 Input Distrust)

## 3. 사장님 실전 활용 지시 템플릿 (Prompt Cheat-Sheet)

신규 프로젝트나 기능 추가 시 아래와 같이 결합하여 지시하시면 됩니다.

### [실전 패턴 A] 실시간 주식/코인 시세 대시보드 구축
> "S-1(토스 미니멀) 스타일에 S-2(TanStack Query)로 5초마다 실시간 시세 갱신하고, S-3(차트 킷)으로 파동 궤적 툴팁 차트 띄워서 배포해라."

### [실전 패턴 B] 유료/회원제 퀀트 알림 서비스 구축
> "S-1(블루칩 PB) 스타일에 S-4(소셜 로그인 완제품) 붙여서 로그인한 유저만 S-3 목표가 전광판 보게 만들고 배포해라."

### [실전 패턴 C] 정밀 입력 금융 계산기 구축
> "S-1(퀀트 터미널) 스타일에 S-5(Zod 검증)로 고점/저점 입력 오류 즉시 잡아내고 S-3 차트로 연결해라."

## 4. 완벽 해결 보증 결론

- **외주 개발비 90% 절감**: 디자인, 인증, 차트, 상태 관리를 직접 짜지 않고 세계 1위 오픈소스 완제품으로 직결.
- **버그 발생률 0%**: 전 세계 수백만 개발자가 검증한 엔진 위에서 돌아가므로 크래시 위험 제로.
- **사장님의 자유**: 사장님은 '어떤 돈 되는 데이터와 공식을 넣을까' 기획에만 100% 집중.

# [05 범용 모던 컴포넌트 킷 규격 및 디자인 프리셋 가이드]

## 1. 개요 및 목적 (Zero-Pixel-Tug 원칙)

본 문서는 화면 구성 시 발생하는 픽셀 조정, 글자 찌그러짐, iframe 하단 짤림 현상을 영구적으로 원천 차단하기 위한 **범용 모던 컴포넌트 킷 규격과 4대 상용 디자인 프리셋**을 정의합니다.

사용자는 복잡한 CSS 수치를 지시할 필요 없이, 본 문서에 정의된 **[컴포넌트 블록] + [디자인 프리셋 번호]**만 지정하면 100% 검증된 상용 수준의 UI/UX가 즉시 조립 및 배포됩니다.

---

## 2. A계열 4대 기초 원소 및 스타일 토큰 (Atoms & Theme)

화면의 '원단과 색상'을 결정하는 불변의 스타일 공식입니다. 폰트 찌그러짐과 색상 충돌을 원천 차단합니다.

| 원소 번호 | 토큰 분류 | 표준 규격 및 역할 | 기술적 보증 가치 |
| :--- | :--- | :--- | :--- |
| **A-1** | **Color Palette** | 칠흑 블랙, 딥 슬레이트, 네온 그린/앰버/레드 | 다크모드 대비비(Contrast Ratio 4.5:1 이상) 완벽 준수 |
| **A-2** | **Typography Scale** | 전광판(1.08rem Bold), 본문(0.92rem), 라벨(0.76rem) | 임베드/모바일에서도 찌그러지지 않는 절대 비례 스케일 |
| **A-3** | **Radius & Spacing** | 모서리 둥글기(6px/8px/14px), 여백(4px/8px/12px 단위) | 8-Point Grid 시스템 기반의 오차 없는 정렬 |
| **A-4** | **Icon System** | 외부 CDN 없는 순수 1em 단색 인라인 SVG 심볼 | 네트워크 랙 0초, 아이콘 깨짐 0% 보장 |

---

## 3. B계열 8대 범용 조립 블록 규격 (Blocks)

A계열의 원단 옷을 입고 화면에 실제로 배치되는 '완제품 레고 블록'입니다.

| 블록 번호 | 컴포넌트 명 | 역할 및 기능 | 자동 적용되는 안전망 |
| :--- | :--- | :--- | :--- |
| **B-1** | **Container (프레임 쉘)** | 전체 화면을 감싸는 최상위 래퍼 | 모바일/PC/iframe 높이를 감지하여 짤림 없는 100% 자동 반응형 여백 부여 |
| **B-2** | **Header / Nav** | 로고, 타이틀, 버전 태그 배치 | 상단 고정 및 결과 노출 시 자동 스위칭 접힘 지원 |
| **B-3** | **Form & Input** | 텍스트/숫자 입력창 및 라벨/힌트 | 포커스 하이라이트, 입력값 유효성 실시간 검증(T1 Input Distrust) |
| **B-4** | **Action Button** | 판독, 리셋, 예시 채우기 버튼 | 클릭 시 햅틱 반응, 비활성화(disabled) 및 로딩 스피너 기본 내장 |
| **B-5** | **Result Card** | 분석 결과를 담는 웅장한 대시보드 | 다크 서피스, 1px 보더 라인, 부드러운 그림자(Elevation) 자동 렌더링 |
| **B-6** | **Status Badge** | [Class 1] 등 핵심 상태 라벨 | 상태 코드에 따라 색상(Green/Amber/Red) 자동 매핑 및 폰트 찌그러짐 방지 |
| **B-7** | **Metric Tile (전광판)** | 1차 목표가, 지지선 등 가격 수치 | 숫자가 한눈에 꽂히는 1.08rem Bold 800 전광판 타이포그래피 고정 |
| **B-8** | **Accordion (서랍)** | 10초 파동 가이드, 도움말 | 클릭 시 부드럽게 펼쳐지는 마이크로 인터랙션 (외부 JS 라이브러리 0KB) |

## 4. 상황별 디자인 프리셋 & Vibe Engine (무한 동적 확장)

지시서에 아래 대표 프리셋 번호를 지정하거나, 원하는 서비스 레퍼런스(P-Custom)를 던지면 최적의 스타일이 1초 만에 자동 생성됩니다.

### [대표 베이스라인 프리셋 4선]
- **[프리셋 1] 월스트리트 퀀트 터미널 (Wall Street Terminal)**
  - 분위기: 헤지펀드 트레이더 전용 블룸버그 터미널 감성 (데이터 밀도 1위)
  - 적용 원소: A-1(칠흑 매트 블랙 `#090d16` + 네온 에메랄드 `#2ea043`), A-3(세미 직각 `6px`)
- **[프리셋 2] 토스 / 애플 미니멀 핀테크 (Toss Minimal)**
  - 분위기: 누구나 편안하게 사용할 수 있는 극상의 모던 심플 감성 (대중적 가독성 1위)
  - 적용 원소: A-1(딥 슬레이트 `#0f172a` + 일렉트릭 블루 `#38bdf8`), A-3(소프트 라운딩 `14px`)
- **[프리셋 3] 바이낸스 크립토 / AI 하이테크 (Crypto High-Tech)**
  - 분위기: 첨단 블록체인 거래소 및 AI 퀀트 플랫폼 감성 (사이버 테크)
  - 적용 원소: A-1(옵시디언 `#0b0e14` + 골드 옐로우 `#f0b90b`), A-3(스탠다드 `8px` 네온 글로우)
- **[프리셋 4] 정통 프라이빗 뱅킹 블루칩 (Private Banking)**
  - 분위기: 대형 증권사 PB센터의 묵직하고 신뢰도 높은 금융 감성 (엔터프라이즈 신뢰)
  - 적용 원소: A-1(클래식 딥 네이비 `#0a192f` + 로얄 골드 `#d4af37`), A-3(모던 라운딩 `8px`)

### [P-Custom 무한 동적 디스패처]
어떤 새로운 도메인(부동산, 이커머스, 커뮤니티 등)을 개발하더라도, 사장님이 **참고 앱이나 분위기 키워드**만 던지면 AI가 1초 만에 A계열 원단(A-1~A-3)을 자동 조색하여 배포합니다:
- `P-Custom: 당근마켓 감성` ➔ 웜 화이트 + 오렌지 액센트 + 16px 소프트 라운딩
- `P-Custom: 노션 미니멀` ➔ 클린 모노톤 + 1px 극세 보더 + 흑백 볼드 타이포
- `P-Custom: 로빈후드` ➔ 딥 차콜 + 네온 라임그린 + 대형 전광판 차트
- `P-Custom: [이미지 캡처/사이트 URL]` ➔ 해당 사이트의 색상 팔레트와 곡률을 1:1 자동 추출

## 5. 사장님 전용 1초 지시 템플릿 (A + B + 예시 조합 치트키)

앞으로 새로운 화면을 만들거나 수정할 때는 아래 공식 하나만 복사해서 던지시면 됩니다.

> **[공식]: `[P-번호 또는 P-Custom 레퍼런스] + [B-번호 블록 조합] + [기능명] = 100% 종결 배포`**

### 실전 지시 예시 1: 완전 신규 위젯 생성
> "docs 05 문서 기반으로, **[프리셋 1: 월스트리트 퀀트]** 테마에 블록은 **[B-3 입력창, B-4 버튼, B-7 전광판 타일]** 조합해서 [RSI 과매수 판독기] 화면 짤림 없이 만들어 배포해라."

### 실전 지시 예시 2: 기존 화면 디자인 전면 교체
> "현재 엘리어트 파동기 화면을 docs 05의 **[프리셋 2: 토스 미니멀]** 스타일로 통째로 갈아입혀서 배포해라."

### 실전 지시 예시 3: P-Custom 동적 확장 지시
> "docs 05의 **[P-Custom: 로빈후드 라임그린 감성]**으로 잡고, **[B-1 임베드 쉘, B-7 전광판]**으로 [급등주 발굴기] 배포해라."

## 6. 완벽 해결 보증 원리 (Zero-Risk)

1. **Zero-Deformation (왜곡 0%)**: 
   - 폰트 크기(A-2)와 차트 높이가 컴포넌트 킷 내부의 토큰 시스템으로 영구 고정되어 폰트가 찌그러지지 않습니다.
2. **Zero-Clipping (짤림 0%)**: 
   - `Container (B-1)`가 브라우저 및 iframe 높이를 실시간 감시하여 짤림을 100% 차단합니다.
3. **Zero-Leak (보안 100%)**: 
   - 화면 구성(UI)은 완벽한 레고 블록으로 화려하게 동작하되, 내부 퀀트 수식과 핵심 알고리즘은 Vercel Serverless Core 뒤에 100% 은닉됩니다.

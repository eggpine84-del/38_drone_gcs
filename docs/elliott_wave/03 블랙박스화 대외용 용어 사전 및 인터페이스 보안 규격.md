# [블랙박스화 대외용 용어 사전 및 인터페이스 보안 규격]

> **보안 원칙**: 내부 32대 로직, 8대 전략 전선, 피보나치 확장 가중치 및 독자적 매뉴얼 공식의 지적 재산권(IP)을 보호하기 위해, 대외 서비스(웹/앱/API)에 노출되는 모든 명칭과 데이터 구조는 본 규격에 따라 100% 마스킹 및 암호화하여 처리한다.

---

## 1. 카드 시스템 블랙박스 매핑 (Card System -> Status Grade)

내부 실전 대응 카드 시스템은 외부 서비스에서 5단계 시스템 상태 등급(Class 1 ~ Class 5)으로 치환되어 노출된다.

| 내부 고유 명칭 (은닉 대상) | 대외 서비스 노출 명칭 | 영문 코드 | 대외 표기 설명 |
| :--- | :--- | :--- | :--- |
| **[BLUE] 럭키** | **[Class 1] 지지 수호** | `STATUS_CLASS_1` | 정상 눌림목 확인 및 지지 반등 유효 구간 |
| **[YELLOW] 경고** | **[Class 2] 변동성 주의** | `STATUS_CLASS_2` | 단기 기준선 이탈 후 익일 회복 여부 관망 구간 |
| **[ORANGE] 위험** | **[Class 3] 비중 축소** | `STATUS_CLASS_3` | 상승 탄력 둔화에 따른 리스크 관리 및 방어 구간 |
| **[RED] 아웃** | **[Class 4] 추세 이탈** | `STATUS_CLASS_4` | 기준 추진 시나리오 무효화 및 포지션 정리 구간 |
| **[BLACK] 즉시 처단** | **[Class 5] 긴급 회피** | `STATUS_CLASS_5` | 절대 방어선 붕괴에 따른 시스템 긴급 퇴각 구간 |

## 2. 8대 전략 전선 블랙박스 매핑 (Battlefield Map -> Macro Boundary)

차트 및 리포트에 표기되는 8대 전선의 위치와 명칭은 공학적 퀀트 용어로 마스킹한다.

| 번호 | 내부 고유 명칭 (은닉 대상) | 대외 서비스 노출 명칭 | 인터페이스 키 | 대외 기능 정의 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | **본진 사수선 (The Origin)** | **베이스라인 플로어** | `line_baseline` | 전체 파동 성립의 절대 기준 최저점 |
| 2 | **동력 보급선 (The Pivot)** | **구조적 반등선** | `line_pivot` | 조정 완료 후 다음 추진 파동 출발 저점 |
| 3 | **에너지 판독선 (0.382 / 0.618)** | **모멘텀 밴드 (L1 / L2)** | `band_momentum_1`, `band_momentum_2` | 되돌림 비율 기반 장세 성격 판별선 |
| 4 | **전선 퇴로 차단선 (Exit Line)** | **추세 경계선** | `line_boundary` | 가짜 돌파 식별 및 단기 되돌림 경계 사선 |
| 5 | **신분 결정선 (1파 고점 Overlap)** | **추진파 검증선** | `line_validation` | 추진 파동 무결성 판별 수평 저항/지지선 |
| 6 | **시스템 무결성 확인선 (S1 Gate)** | **1차 목표 관문** | `target_gate_s1` | 메인 추진 파동 확정 분기 가격선 |
| 7 | **광기 측정선 (Channel Top)** | **채널 상한선** | `channel_ceiling` | 모멘텀 과열 및 최종 목표 실현 상단선 |
| 8 | **사망 선고선 (2-4 Trendline)** | **최종 추세선** | `terminal_trendline` | 중장기 사이클 종결 확인 하방 이탈선 |

## 3. 32대 로직 및 특수 필터 블랙박스 매핑 (Matrix & Quant Filter)

내부 32대 파동 매트릭스 및 4대 특수 필터는 통계 분석 모델 코드로 암호화한다.

| 구분 | 내부 고유 명칭 (은닉 대상) | 대외 서비스 노출 명칭 | 모델 식별 코드 |
| :--- | :--- | :--- | :--- |
| **조합 1~4** | 2파 38.2% 강세장 4형제 | 초강세 추진 모델 (A타입) | `MODEL_A01` ~ `MODEL_A04` |
| **조합 5~8** | 2파 61.8% 매집형 4형제 | 안정 매집 추진 모델 (B타입) | `MODEL_B01` ~ `MODEL_B04` |
| **조합 9~16** | 4파 38.2% 강세 지속 / 61.8% 약화형 | 중기 파동 지속/보정 모델 | `MODEL_C01` ~ `MODEL_C08` |
| **조합 17~24**| 5파 종결형 (표준 38.2% / 연장 61.8%) | 최종 목표 수렴 모델 | `MODEL_D01` ~ `MODEL_D08` |
| **조합 25~32**| 하락 ABC (가속형 / 희망고문형) | 조정 국면 전이 모델 | `MODEL_E01` ~ `MODEL_E08` |
| **특수필터 01**| 가속 엔진 점화 (Nitro: 23.6%) | 급속 모멘텀 트리거 | `FILTER_FAST_TRACK` |
| **특수필터 02**| 심해 매집형 (Deep: 76.4%~78.6%) | 수급 응축 밴드 | `FILTER_DEEP_ACCUMULATION` |
| **특수필터 03**| 5파 폭주 확정 (1파 ≈ 3파 응축) | 추진력 전이 시그널 | `FILTER_EXTENSION_SHIFT` |
| **특수필터 04**| 확장 플랫 트랩 및 컵앤핸들 (VCP) | 변동성 수축 돌파 시그널 | `FILTER_VCP_BREAKOUT` |
| **특수필터 05**| S3 무중력 폭주 (2.618 돌파) | 초과 확장 추세 모드 | `FILTER_HYPER_EXTENSION` |
| **특수필터 06**| 다이아고날 생존 로직 | 쐐기형 구조 보정 모드 | `FILTER_WEDGE_ADJUSTMENT` |

## 4. 아키텍처 및 인터페이스 보안 4대 수칙

1. **Zero-Client Math (클라이언트 연산 금지)**:
   - 웹 브라우저의 Javascript 또는 모바일 앱 클라이언트 내부에서 피보나치 비율(0.382, 0.618, 1.618, 2.618)이나 32대 분기 알고리즘을 계산하는 코드를 일체 포함하지 않는다.
   - 모든 연산은 오직 비공개 백엔드 서버(Core)에서만 순수 함수로 수행한다.

2. **Ratio Concealment (비율 수치 비공개)**:
   - 클라이언트 화면에는 사용자가 투입한 기준 가격을 토대로 계산된 최종 원화 가격(예: 84,500원)만 출력하며, "1.618배", "38.2% 조정" 등의 비율 수치는 화면 및 네트워크 페이로드에 노출하지 않는다.

3. **Payload Sanitization (네트워크 응답 살균)**:
   - 백엔드에서 프론트엔드로 전달하는 JSON 응답에는 `wave1_high`, `deadline_3pct_down`, `nitro_active` 같은 내부 개발 변수명을 사용하지 않고, 본 규격에 명시된 식별 코드(`p_base`, `p_t1`, `p_t2`, `status_class`)로 치환하여 전송한다.

4. **Rate Limiting & Anti-Scraping (역공학 방어)**:
   - 사용자가 임의의 숫자를 대량으로 대입하여 피보나치 가중치 공식을 역추출하지 못하도록 동일 IP/계정당 분당 조회 횟수를 제한(Rate Limit)한다.

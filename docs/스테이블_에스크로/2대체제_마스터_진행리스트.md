# SafeLink 2대 체제 (국내 거래 & 해외 거래) 진행리스트

## 1. 개요 및 전환 방향
- 배경: 복잡한 택배사 크롤링, 외부 다운로드 링크 제출, 주관적 외주 분쟁 등 비본질적 요소 100% 제거.
- 핵심: 이용자가 0.1초 만에 직관적으로 선택하는 [국내 거래]와 [해외 거래] 딱 2대 체제로 극단적 단순화 및 범용성 극대화.
- 명칭 체계:
  * [1. 국내 거래]: 물품 안심송금 · 중고/직거래 (원화 KRW / 서류 불필요 순수 안심금고)
  * [2. 해외 거래]: B2B 무역 · 해외 사입 · 샘플비 (테더 USDT / 상업송장 + B/L 선적 서류)
- 원칙: 사기 원천 차단 + 불발 시 100% 원금 자금 회수(Timeout Refund) 절대 보장.

---

## 2. 완료 현황 (Base)
- [x] Non-Custodial 탈중앙 에스크로 코어 FSM 구축 (113개 핀-테스트 100% Pass)
- [x] 4자리 간편 PIN 및 5회 연속 오류 시 영구 동결 가드레일 (브루트포스 차단)
- [x] 해외 무역 슬라이딩 요율(최대 150불 하드캡) 및 상업송장(`invoice_no`) 코어 엔진
- [x] 사내 지출결의 및 세무 증빙용 A4 무역 영수증 웹 뷰 구축 (`/receipt/{id}`)
- [x] 다국어(영문/중문) 간이 토글 및 보증서 UI 기반

## 3. 세부 진행 로드맵 (Roadmap)

### Phase 1: 메인 UI 초슬림 2대 체제 개편 (국내 거래 vs 해외 거래)
- [x] 메인 생성 화면(`index.html`): 4대 분기 폐기 ➔ [국내 거래] vs [해외 거래] 딱 2개 라디오(버튼)로 단일화
- [x] 국내 거래 UI: 택배사/링크 입력창 일체 제거 ➔ 순수 안심금고 폼 (금액, PIN, 기한 선택: 72시간 기본 vs 7일 명절·여유)
- [x] 해외 거래 UI: 상업송장(Invoice No.) + B2B 해운/항공 기한(30D/14D) 전용 폼 바인딩
- [x] 해외 거래 스마트 입력 전환: [해외 거래] 선택 즉시 통화 `USDT` 자동 고정, 달러($) 단위 입력창 전환 및 150불 수수료 하드캡 실시간 뱃지 노출
- [x] 보증서 화면(`claim.html`): 군더더기 제거 ➔ 국내 거래(물품 확인 후 승인) / 해외 거래(B/L 선적 확인 후 승인) 2종으로 단순화
- [x] 해외 보증서 글로벌 UX: 해외 거래 시 영문(EN) 기본 언어 자동 감지 / 다국어(KO/EN/ZH) 지원 및 사내 지출결의용 [A4 영수증 인쇄] 전면 노출

### Phase 2: 자금 회수 & 100% 환불 안전핀 전수 검증 (최우선 과제)
- [x] 판매자 미등록 즉시 취소: 판매자가 지갑 등록 전이면 구매자가 1초 만에 100% 원금 즉시 회수
- [x] 국내 거래 배송 지연 방어선: 구매자 보증서 화면에 [택배 지연 - 기한 3일 연장하기 (1회 한정)] 원클릭 안전핀 탑재
- [x] 국내 거래 미도착 잠적 방어선: 구매자 [미도착 신고] 시 자동 송금 즉시 영구 정지(Freeze) 및 100% 원금 환불 보장
- [x] 국내 거래 환불 검증: 거래 불발 또는 물품 미전달 시 구매자 원금 100% 즉시 환불
- [x] 해외 거래 환불 검증: 기한(30D) 내 B/L 선적 서류 미등록 시 판매자 잠적 ➔ 구매자 100% 자동 환불
- [x] 백엔드 코어 호환성: `DOMESTIC`/`TRADE` 2대 체제 전환 시 기존 113개 핀-테스트 100% 무충돌 호환 어댑터 탑재
- [x] 2대 모드 풀스택 E2E 핀-테스트 작성 (정상 정산 & 타임락 만료 환불 100% Pass)

### Phase 3: 입금 UX 및 표시 정규화
- [x] 입금 대기 화면(`deposit_web.py`): 국내 거래(원화 KRW 대문짝 표기) vs 해외 거래(USDT 달러 대문짝 + 인보이스 뱃지) 분리 정규화
- [x] 동적 OG 공유 카드(`/api/og/{id}`): 국내(원화 안심금고) / 해외(USDT 글로벌 무역 보증서) 맞춤 썸네일 노출

### Phase 4: 사장님 전용 텔레그램 실시간 입금 비서 (Alert Bot)
- [ ] 2대 체제(국내 원화 1.0% / 해외 USDT 슬라이딩) 정산 완료 즉시 사장님 텔레그램으로 0.1초 입금 푸시 발송
- [ ] 알림 명세: 거래 ID, 거래 모드(국내/해외), 거래액, 인보이스/B/L 번호, 입금 수수료, 누적 수익 잔고
- [ ] 사장님 릴레이어 지갑 가스비(폴리곤 등) 잔고 부족 시 사전 경고 알림
- [ ] 봇 장애/지연 시에도 에스크로 트랜잭션은 100% 정상 완결되는 I/O 격리 설계

### Phase 5-A: EVM 인프라 구축 및 테스트넷 검증 (지금 진행 가능)
- [ ] 수파베이스(Supabase PostgreSQL) 클라우드 DB 연동 (서버리스 100% 호환 오프체인 원장 영속화)
- [ ] 수수료 10원 미만 체인 선정 (Polygon / Base / Arbitrum)
- [ ] 가스비 대납 엔진(Gasless Meta-Tx) 탑재 (이용자는 가스비 코인 0원 보유해도 완전 무료 이용)
- [ ] 고성능 Go 온체인 릴레이어(Go-Ethereum Relayer) 탑재 (초고속 Nonce 큐잉, 가스비 대납 서명 및 무결점 RPC 통신)

### Phase 5-B: 메인넷 실전 배포 (원화 스테이블 제도권 진입 후 진행)
- [ ] 2대 체제 통합 `SafeLinkEscrow.sol` 컨트랙트 온체인 배포 및 1 USDT 실전 소액 회수 검증
- [ ] 상용 도메인(`safelink.kr` 등) DNS 연결, HTTPS 적용 및 배포 환경변수 확정

### Phase 6: 대액(컨테이너 본 발주) 확장 트랙 (Scale-Up)
- [ ] 마일스톤 분할 결제 (30% 계약금 + 70% 선적 잔금)
- [ ] 관세청 유니패스(UNIPASS) 수입화물진행정보 API 자동 교차 검증 (B/L 자동 대조)
- [ ] 기업용 사내 다중 승인 결재선 (Multi-Sig Approval)

## 4. 2대 모드 핵심 비교표

| 구분 | 1. 국내 거래 (Domestic Safe Pay) | 2. 해외 거래 (Global Trade Pay) |
| :--- | :--- | :--- |
| **주요 대상** | 국내 중고거래, 개인 간 실물 거래, 직거래 | B2B 수출입, 중국/해외 사입, 샘플비 송금 |
| **핵심 통화** | 원화 (KRW) 기준 | 테더 (USDT) 달러 기준 |
| **필요 서류** | 서류 불필요 (순수 안심금고) | 상업송장(Invoice No.) + 선하증권(B/L) |
| **수수료 체계** | 건당 1.0% (소액 고정 저수수료) | 슬라이딩 요율 (0.3%~1.0%, 최대 150불) |
| **기본 기한** | 24시간 ~ 72시간 (명절·여유 7일 / 구매자 1회 3일 연장 지원) | 7일(특송) ~ 30일(해운 컨테이너) |
| **환불 조건** | 물품 불발 시 즉시 취소 / 미승인 만료 환불 | B/L 미선적 잠적 시 30일 만료 100% 환불 |

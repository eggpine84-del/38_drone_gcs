# [핵심 목적] 대기업식 토큰 폭탄(스크린샷/DOM 전송)을 배제하고, 로컬 연산 기반의 무비용 E2E 검증 체계 구축

---

## 1. 대기업식 vs 초절약형 E2E 비교

| 구분 | 대기업식 E2E (토큰 폭탄형) | 초절약형 실무 E2E (우리의 방식) |
| :--- | :--- | :--- |
| **실행 주체** | AI가 직접 브라우저 조작 및 관찰 | 로컬 CLI 스크립트가 헤드리스 브라우저 조작 |
| **검증 데이터** | 고해상도 스크린샷(Vision), 거대 HTML DOM 전송 | 로컬 성공/실패 종료 코드(`exit 0` / `exit 1`) |
| **토큰 소모량** | 1회 테스트당 5만 ~ 20만 토큰 소모 | **성공 시 0 토큰 (Zero Token)** |
| **에러 대응** | 전체 화면 다시 캡처 후 분석 | 실패한 지점의 단 1줄 에러 로그만 AI에 주입 |
| **실행 비용** | 월 수십~수백만 원 API 비용 발생 | **0원 (로컬 CPU 무료 연산)** |

## 2. 3대 초절약형 E2E 접목 기술

### ① 헤드리스 로컬 E2E 러너 (Playwright Headless)
- **원리**: 브라우저 창을 화면에 띄우지 않고 백그라운드(Headless) 프로세스로 실행하여 로봇이 버튼 클릭, 입력, 이동 수행.
- **토큰 소모**: **0 토큰** (로컬 Node/Python 프로세스 연산).
- **검증 방식**:
  - `page.goto("http://localhost:3000")`
  - `page.click("#login-btn")`
  - `expect(page.locator("#dashboard")).toBeVisible()`
  - 성공 시 `exit 0` 반환 ➔ AI 개입 없이 파이프라인 즉시 PASS.

### ② HTTP/API 시나리오 검증기 (Contract / API Flow)
- **원리**: 무거운 브라우저를 띄우지 않고, 실제 브라우저가 주고받는 순차적 HTTP 요청(로그인 쿠키 획득 ➔ 데이터 조회 ➔ 결제 요청)을 로컬 스크립트로 0.1초 만에 연속 발사.
- **토큰 소모**: **0 토큰**.
- **장점**: 브라우저 렌더링 부하 없이 서버의 E2E 비즈니스 플로우를 가장 빠르고 가볍게 검증.

### ③ Pinpoint Error Feeding (오류 핀포인트 주입)
- **원리**: E2E 테스트가 실패했을 때만, 실패한 엘리먼트 정보와 1줄 스택트레이스만 AI에게 전달.
- **비교**:
  - 나쁜 예: 화면 전체 스크린샷(10,000 토큰) + 3,000줄 HTML DOM(20,000 토큰) 전송
  - 좋은 예: `"Error: #submit-btn not clickable at page.py:42 (Selector Timeout)"` (단 20 토큰)

## 3. 우리 시스템(7대 훅 파이프라인)과의 접목 설계

```text
[1. 비즈니스 코드 작성 완료]
       ↓
[2. 단위/핀-테스트 실행 (pytest)] ──(0 토큰)──► 통과
       ↓
[3. 초절약형 E2E 로컬 러너 실행] ──(0 토큰)──► Playwright 백그라운드 구동
       ├── [성공 (exit 0)] ➔ 즉시 4단계로 통과 (소모 토큰: 0개)
       └── [실패 (exit 1)] ➔ 1줄 오류 로그만 AI에 주입 (소모 토큰: 50개 미만) ➔ 핀포인트 수리
       ↓
[4. 7번 Git Diff 무결성 가드] ──(0 토큰)──► 유실/날림 감시
       ↓
[5. 최종 커밋 승인 (/approve-local)]
```

## 4. 실무 도입 로드맵 (필요 시 점진적 확장)

1. **1단계 (현재 완료)**: Pure Core 단위 테스트 + 7대 방탄 훅 (토큰 0원 안전망 완비).
2. **2단계 (화면 도입 시)**: Shell 영역의 웹 페이지 검증용 `tests/e2e/` 로컬 스크립트 1개 배치.
3. **3단계 (게이트 연결)**: `.agents/scripts/test_gate.py`에 E2E 러너를 체인 연결하여 테스트 성공 시 자동으로 E2E까지 0원으로 무결점 검증 완수.

# 신규 메뉴(수직 슬라이스) 10분 추가 실전 가이드

> **철칙**: 메뉴 하나당 폴더 하나(src/features/<기능명>/), 다른 메뉴의 내부 코드를 절대 훔쳐보지 않는다.

---

## 3단계 초고속 추가 공식

### Step 1. 표준 견본 폴더 복제 (10초)
기존에 준비된 src/features/sample_crud/를 그대로 복사하여 새 기능 폴더를 만듭니다:
`ash
cp -r src/features/sample_crud src/features/orders
cp -r tests/test_features/sample_crud tests/test_features/orders
`

### Step 2. 1:1 수직 슬라이스 내부 부품 구성 (5분)
1. **Core (core/orders_core.py)**: 100% Pure Function 비즈니스 유효성 검증
2. **Repository (shell/orders_repository.py)**: DB 연결 및 파라미터화(?) CRUD 쿼리
3. **Template (shell/templates/orders_panel.html)**: Tailwind + HTMX 프래그먼트
4. **Router (shell/orders_router.py)**: FastAPI APIRouter 정의 (prefix='/api/features/orders')

### Step 3. main.py에 라우터 1줄 등록 & 동적 메뉴 연동 (1분)
1. main.py에 라우터 등록:
`python
from src.features.orders.shell.orders_router import router as orders_router
app.include_router(orders_router)
`
2. 대시보드 화면(/settings)의 **'메뉴 관리'** 탭에서 이름과 아이콘을 등록하면 실시간으로 사이드바에 꽂힙니다.

---

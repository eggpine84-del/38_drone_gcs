## 1. 개요

본 문서는 공식 엔진 깊숙한 곳에 내장되어 있으나 대다수 사용자가 알지 못하는 **상위 0.1% 전용 4대 실전 치트키**의 개념과 사용법을 정리한 매뉴얼이다.

---

## 2. 4대 실전 치트키 상세 명세

### ① `/grill-me` (역취조 기획 인터뷰 모드)
- **개념**: 
  - 사장님이 기획서를 직접 쓰며 머리를 싸매는 대신, **AI가 사장님을 반대로 인터뷰(취조)하여 기획서를 뽑아내는 모드**.
- **사용법**: 
  - 채팅창에 `/grill-me`를 치고 만들고 싶은 대략적인 기능(예: "원생 출결 알림톡 기능")을 던진다.
- **동작 방식**: 
  - AI가 코드를 바로 짜지 않고, 기획에서 놓치기 쉬운 엣지케이스(예외 상황, 시간대, 실패 시 대체 수단 등)를 사장님에게 객관식/단답형 질문으로 계속 던진다.
  - 사장님이 단답으로 대답만 툭툭 던지면, 3분 만에 모든 변수가 통제된 100점짜리 기획서가 완성된다.

---

### ② `/learn` (실수 영구 박제 메모리)
- **개념**: 
  - AI가 실수해서 한번 혼났던 내용을 **에이전트의 뇌(영구 글로벌 메모리)에 영구 각인**시키는 기능.
- **사용법**: 
  - AI의 엉뚱한 행동이나 실수를 올바르게 바로잡아준 직후, 채팅창에 `/learn`을 입력한다.
- **동작 방식**: 
  - 현재 채팅 세션이 끝나거나 새로운 프로젝트를 시작하더라도 영구 보존되는 전용 메모리 그래프에 해당 교정 규칙을 저장한다.
  - 두 번 다시 동일한 실수를 반복하지 않도록 뇌에 문신을 새긴다.

---

### ③ `PostToolUse` 훅 (저장 직후 0.01초 자동 미용실)
- **개념**: 
  - AI가 코드를 수정한 직후 0.01초 만에 로컬 컴퓨터가 코드를 칼각으로 정렬하고 뒤처리하는 하녀 훅.
- **비용**: 
  - **토큰 소모량 0% (완전 무료)**. 사장님 컴퓨터의 CPU가 파이썬/도구 프로세스로 돌리므로 LLM 비용이 1원도 들지 않는다.
- **적용 위치**: 
  - `.agents/hooks.json` 내 `PostToolUse` 블록에 연결.
- **대표 용도**:
  1. **코드 자동 정렬 (Auto-Formatter)**: 
     - AI가 짠 코드의 삐뚤빼뚤한 들여쓰기, 불필요한 빈 줄, 쓰지 않는 import를 0.01초 만에 표준 규격(PEP8 등)으로 칼각 정리.
  2. **즉각적인 문법 검사 (Instant Linter)**: 
     - 괄호 덜 닫힘, 변수 오타를 파일 저장 즉시 0.05초 만에 감지하여 AI에게 바로 피드백 주입.

---

### ④ `browser_subagent` (진짜 브라우저 화면 녹화 검증)
- **개념**: 
  - AI가 말로만 "잘 됩니다"라고 속이는 것을 막기 위해, **진짜 크롬 브라우저를 띄워 마우스를 조작하고 화면을 녹화해 오는 서브 에이전트**.
- **동작 방식**: 
  - 실제 웹 서버에 접속하여 버튼을 클릭하고, 폼을 입력하고, 화면 이동을 직접 수행한다.
  - 모든 조작 과정을 **WebP 동영상이나 스크린샷 짤방으로 자동 녹화**하여 사장님 화면에 증빙 자료로 제출한다.
- **효과**: 
  - 사장님이 브라우저를 직접 켜서 마우스로 눌러볼 필요 없이, AI가 떠온 3초짜리 녹화 비디오만 보고 정상 작동을 1초 만에 육안으로 검증할 수 있다.

## 3. 요약 및 실무 활용 팁

| 치트키 | 사용 시점 | 핵심 가치 |
| :--- | :--- | :--- |
| **`/grill-me`** | 기능 만들기 전 (기획 단계) | 기획서 작성 고통 0, 엣지케이스 자동 발굴 |
| **`/learn`** | AI가 실수해서 바로잡았을 때 | 같은 실수 평생 재발 방지 (영구 메모리) |
| **`PostToolUse`** | 코드 수정 직후 (실시간) | 토큰 0개로 코드 칼각 정렬 및 오타 즉시 적발 |
| **`browser_subagent`**| UI/기능 완성 후 (검증 단계) | 화면 녹화 비디오로 100% 무결성 육안 검증 |

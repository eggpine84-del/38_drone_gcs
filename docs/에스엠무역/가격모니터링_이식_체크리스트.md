# 가격 모니터링 타 업체 이식 실전 체크리스트

새로운 업체(테넌트)에 가격 모니터링을 이식할 때, 오늘 겪었던 오류(설정 롤백, 제품 뒤섞임, 엑셀 불일치)를 100% 방지하기 위해 위에서부터 순서대로 체크하며 실행합니다.

---

### [1. 테넌트 설정 및 메뉴 등록]
- [ ] 1. `config/tenants/<신규테넌트>/price_monitor_config.txt` 생성 (에스엠무역 파일 복사)
- [ ] 2. `price_monitor_config.txt` 내 제품명, 기준가격, 제외키워드를 신규 업체에 맞게 초기 입력
- [ ] 3. `config/tenants/<신규테넌트>/menus.txt`에 메뉴 1줄 추가
  `price_monitor | 가격 모니터링 | shopping-bag | /price-monitor | 회사 | 전체`

---

### [2. 엔진 경로 및 원클릭 bat 패키징]
- [ ] 4. `price_monitor_engine.py`의 `CONFIG_FILE_PATH`가 신규 테넌트 폴더를 바라보도록 설정 확인
- [ ] 5. 신규 업체용 `<신규업체명>_모니터링_엔진등록.bat` 파일 준비 및 프로토콜 링크 일치 확인
- [ ] 6. 로컬 엔진 포트(기본 8088) 및 CORS / Private Network Access(PNA) 헤더 3대장 유지 확인

---

### [3. 화면 렌더링 & 설정 롤백 방지 검증]
- [ ] 7. **기본값 부활(롤백) 방지**: 웹에서 제품을 다 지우고 [설정 저장] 시 과거 기본값이 강제로 되살아나지 않는지 확인
- [ ] 8. **타이핑 중 리셋 방지**: 5초 상태 체크 타이머가 도는 중에 `isConfigLoaded` 플래그로 인해 입력창이 초기화되지 않는지 확인
- [ ] 9. `price_monitor_view.py` 파일 라인 수가 300줄 이하인지 확인 (코드 헌법 준수)

---

### [4. 정렬 및 엑셀 일치 3대 원칙 검증]
- [ ] 10. **제품 등록 순서(`prod_idx`) 보존**: 가나다순으로 제품이 뒤섞이지 않고, 사장님이 등록한 순서대로 1번 제품 ➔ 2번 제품 묶여서 나오는지 확인
- [ ] 11. **제품별 완전 격리 + 위반 최저가순**: 다른 제품의 위반 항목이 중간에 끼어들지 않고, 각 제품 안에서만 `[위반]` 항목이 최상단에 낮은 가격순으로 정렬되는지 확인
- [ ] 12. **엑셀과 웹 1:1 완벽 일치**: 바탕화면에 생성된 엑셀 파일 행 순서와 웹 테이블 행 순서가 정확히 일치하는지 대조

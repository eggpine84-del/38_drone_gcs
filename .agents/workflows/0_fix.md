> **원칙**: 기존 코드/예외/로그 임의 변형·삭제 금지. Zero Deletion.
> 대상 바인딩: 일일_작업일지.md의 최상단 미완료([ ]) 항목을 대상 작업으로 즉시 자동 연계 착수.
1. **템플릿 열람**: `view_file`로 `templates/03 디버그 템플릿.md` 열람.
2. **서식 1:1 전수 출력**: 에러 로그 원문, Root Cause 3대 가설, 핀포인트 수정 계획(위치/전후/사유)을 **오직 채팅창에만 직접 출력**.
3. **재현 핀테스트 선작성**: 실패(Red) 확인 ➔ 핀포인트 수리 ➔ All-Green(S4) 검증 완료.

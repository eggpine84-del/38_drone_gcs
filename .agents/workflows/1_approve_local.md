---

[로컬 안전 승인 명령]
1. 현재 진행 중인 기획/구현 사항을 승인하되, '상용 배포 생략 모드'로 가동한다.
2. 핀-테스트 및 전체 테스트 스위트를 실행하여 100% Pass(Green)를 검증하라.
3. 작업 내역을 로컬 Git 커밋으로 안전하게 기록하라.
4. 절대 git push 및 Vercel 배포를 진행하지 말고, 로컬 검증 완료 상태와 변경 내역을 보고한 뒤 사장님의 배포 결재를 대기하라.

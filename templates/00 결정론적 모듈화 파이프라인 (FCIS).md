## 2. FUNCTIONAL CORE (기능적 코어)

### [Core 핵심 원칙 및 정의]
- 상기 6대 Shell 요소를 포함하여, 상태 변경을 유발하는 **모든 외부 의존성(Side-Effect)을 100% 격리 및 제거한다.**
- 외부 변수 없음 / 100% 결정론적 0과 1의 세계
- 부작용(Side-Effect) 제로 / **초고속 검증**: DB/네트워크 Mock 없이 순수 입출력만으로 0.001초 내 단위 테스트 가능
- 동일 Input ➔ 언제나 동일 Output
- **Table-Driven Dispatch**: 3개 이상 경로/분기 시 `if-elif` 금지, 무순서 Dict 매핑으로 순서 꼬임 0% 격리

### [Core 구성 노드]
- **`### Pure Input`**  
  `(순수 입력 데이터)`
- **`Sub-IPO 1`**  
  `(데이터 가공)`
- **`Sub-IPO 2`**  
  `(핵심 연산)`
- **`Sub-IPO 3`**  
  `(보조 계산)`
- **`### Pure Output`**  
  `(계산 결과)`

## 3. 전체 파이프라인 데이터 흐름 (Edges & Labels)

### A. Shell ➔ Core (데이터 수집 및 주입)
1. **`### 사용자 UI / 버튼`** ──[Raw Input 수집]──► **`### Pure Input`**
2. **`### 데이터베이스 DB`** ──[데이터 조회]──► **`### Pure Input`**
3. **`### 시스템 / OS 상태 (시간, 난수, 환경변수, 센서)`** ──[시간/난수/환경변수 주입]──► **`### Pure Input`**

### B. Core 내부 연산 파이프라인 (Sub-IPO Flow)
1. **`### Pure Input (순수 입력 데이터)`** ──► **`Sub-IPO 1 (데이터 가공)`**
2. **`Sub-IPO 1 (데이터 가공)`** ──► **`Sub-IPO 2 (핵심 연산)`**
3. **`Sub-IPO 1 (데이터 가공)`** ──► **`Sub-IPO 3 (보조 계산)`**
4. **`Sub-IPO 3 (보조 계산)`** ──► **`Sub-IPO 2 (핵심 연산)`**
5. **`Sub-IPO 2 (핵심 연산)`** ──► **`### Pure Output (계산 결과)`**

### C. Core ➔ Shell (결과 반영 및 저장)
1. **`### Pure Output (계산 결과)`** ──[Side Effect (결과 적용)]──► **`### 네트워크 / API`**
2. **`### Pure Output (계산 결과)`** ──[저장]──► **`### 파일 시스템`**
